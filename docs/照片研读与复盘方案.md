## 2. 数据模型

```sql
-- 参考片标记：1 = 收藏的参考作品（默认走研读），0 = 自己拍的（默认走复盘）
ALTER TABLE items ADD COLUMN reference INTEGER NOT NULL DEFAULT 0;

CREATE TABLE IF NOT EXISTS photo_notes (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  item_id    INTEGER NOT NULL,
  parent_id  INTEGER,                        -- 追问指向父笔记；NULL = 线程根
  kind       TEXT NOT NULL,                  -- question | answer | insight | intent | tech
  mode       TEXT NOT NULL DEFAULT 'study',  -- study | review
  body       TEXT NOT NULL,
  region     TEXT,                           -- JSON {x,y,w,h} 归一化；NULL = 整图
  author     TEXT NOT NULL,                  -- me | ai
  tags       TEXT NOT NULL DEFAULT '[]',     -- JSON 数组，技法标签
  created_at INTEGER NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_photo_notes_item ON photo_notes(item_id, id);
CREATE INDEX IF NOT EXISTS idx_photo_notes_parent ON photo_notes(parent_id);
```

`db.ts` 里的写法：`ensureColumn(...)` 那一片加一行，`db.exec()` 那个大字符串里加建表语句（跟 `facets` 表并排）。

### 为什么坐标存归一化

`region` 用 0–1 相对值，不是像素：

- 缩略图 260 / 720 / 1440 三档切换不用换算
- 灯箱缩放、平移、旋转不用换算（百分比定位自动跟随）
- 导出到 Markdown / FlowUs 不用换算

**换算只发生在一处**：拖框结束时，屏幕坐标除以图片显示尺寸。

### 3.2 AI 反问能力

文件：`src/main/llm/capabilities/socratic.ts`（已写好）

核心是**轮次护栏**，代码里双重保险：

```ts
const aiTurns = history.filter((t) => t.role === 'ai').length
const mustExplain = skipSocratic || aiTurns >= 2   // 硬上限
// ...调用模型之后
if (mustExplain) stage = 'explain'                 // 模型还想反问就扳回来
```

提示词全文：

```
你是带学生读片的摄影老师。学生会圈出画面的一块区域并向你提问。

铁律（按重要性排序）：
1. 先让学生自己观察，别一上来就给答案。第一次回应必须是一个能引导他看的问题。
2. 最多反问两轮。已经反问过两轮就必须给出明确解释，不许再问。
3. 学生说「直接告诉我」时，立刻解释，不要反问。
4. 所有解释都要指向画面里可观察的证据：边缘软硬、色温冷暖、明暗比例、视线方向、
   景深虚实、高光落点。禁止「构图很好」「氛围很棒」这类没有信息的空话。
5. 拿不准就直说不确定，不要编造光源、参数、器材或拍摄手法。
6. 一次只说一件事，别一次抛出三个问题。
7. 中文回答，控制在 120 字以内。

输出 JSON：{"stage":"probe","text":"..."}
stage 取 probe 表示反问，explain 表示给出答案。
```

每轮要把「已反问次数 / 2」明确写进 user message，模型才知道该不该收。

### 3.3 成本控制

现在送整图 + 文字描述区域位置。想再省，可以改成只送圈选区域的裁切图——需要给 `CapabilityContext` 加 `imageRegion(itemId, region)`，用 sharp 裁完再压。**P1 先不做**，跑通再说。

## 5. 渲染层

### 5.1 坐标系：最容易翻车

`Lightbox.tsx` 现在的图层结构：

```
外层 div（overflow-hidden, pointer-events-none）
└ 内层 div   width=displayW  height=displayH  transform=translate3d(offsetX, offsetY)
  └ img      left=layerLeft  top=layerTop  width=layerW  height=layerH  transform=rotate(deg)
```

四个变量的含义（`Lightbox.tsx:207-215`）：

| 变量 | 含义 |
| --- | --- |
| `displayW/H` | 旋转**后**的外接尺寸 |
| `layerW/H` | 图片自身尺寸（旋转**前**） |
| `layerLeft/Top` | 图片在外接框里的居中偏移 `(displayW - layerW) / 2` |
| `offsetX/Y` | 外接框在视口中的位置 |

**正确做法**：`RegionLayer` 不要放进外层 div 用百分比定位（会错位），而是**复制 img 的整套定位样式**，跟它并排叠一层：

```tsx
<img style={{ left: layerLeft, top: layerTop, width: layerW, height: layerH, transform: rotate }} />
<div style={{ left: layerLeft, top: layerTop, width: layerW, height: layerH, transform: rotate,
              position: 'absolute', pointerEvents: 'auto' }}>
  {regions.map(r => <div style={{ left: `${r.x*100}%`, top: `${r.y*100}%`,
                                  width: `${r.w*100}%`, height: `${r.h*100}%` }} />)}
</div>
```

这样它跟图片像素级对齐，缩放、平移、旋转全部自动跟随，一行都不用算。

### 5.2 拖框换算

```ts
const rect = photoRef.current.getBoundingClientRect()   // 图片实际显示区域
const region = {
  x: (clientX - rect.left) / rect.width,
  y: (clientY - rect.top) / rect.height,
  w: dragW / rect.width,
  h: dragH / rect.height
}
// 夹到 0-1，宽高小于 0.02 视为误触直接丢弃
```

⚠️ 图片旋转时 `getBoundingClientRect()` 给的是外接矩形。**P1 建议旋转角度不为 0 时直接禁用框选**，提示「转正后再框」，比强行算三角函数靠谱得多。

## 6. 模式差异

同一套界面，AI 首句不同：

| | 研读 study | 复盘 review |
| --- | --- | --- |
| 对象 | 别人拍的好片 | 自己拍的片子 |
| AI 首问 | 你觉得这块的作用是什么 | 你当时想拍成什么感觉 |
| 产出 | 一条可以偷的手法 | 一条下次注意 |

默认判定：`items.reference === 1` → 研读，否则复盘。面板顶部给开关可手动切。

`reference` 目前没地方设置，P1 可以先在详情面板加个「这是参考片」勾选框。

## 7. 交互细节

| 场景 | 行为 |
| --- | --- |
| 点已存在的框 | 右侧面板滚动到对应线程并高亮 |
| hover 框 | 显示该框第一句提问（截断 24 字） |
| 点气泡里「框 1」标签 | 图上对应的框闪一下 |
| AI 回复中 | 气泡显示「正在想…」呼吸态，输入框禁用 |
| AI 未配置 | 面板顶部一行灰字「未启用大模型」，纯文字笔记仍可用 |
| 达反问上限 | 气泡角标从「反问」变「解释」 |

**最后一条最容易漏**：大模型没配时，研读面板不能整个不可用，手工记笔记必须还能用。否则功能一上线就是坏的。
