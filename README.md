## 为什么用它

拍完一场照片，系统自带的文件管理器不够用，网盘又不想把原图传上去——月相补的就是这一段：

- **照片不搬家**：只在你指定的文件夹里建一份索引和缩略图，原图原地不动、不改名、不删除。
- **从一堆照片到客户拿到的成品**：打星挑片 → 生成客户选片页 → 客户回传 → 只看客户要的 → 导出成品。
- **学别人的片子**：人像维度（景别、光线、氛围…）标好，灯箱里圈出一块画面提问，AI 先反问你两轮再给答案。
- **用中文找图**：不用记文件名，「海边的日落」「低饱和冷色调的街拍」都能搜。

## 安装

**懒得自己动手？让 AI 代劳**

把安装包所在路径发给你常用的 AI 助手，附一句：

> 帮我装好月相：Windows 直接运行 `release` 里的 `月相 Setup 安装包.exe`，按默认设置装完；macOS 打开 `release` 里的 dmg，把「月相」拖进「应用程序」。装完打开一次，确认能启动。

**Windows**

1. 打开仓库里的 `release` 目录，双击最新的 `月相 Setup <版本号>.exe`。
2. 安装包没有买代码签名，Windows 会提示「已保护你的电脑」→ 点「更多信息」→「仍要运行」。
3. 装完从开始菜单打开「月相」。

**macOS**

macOS 版需要自己构建（原生模块必须在 macOS 上安装，没法在 Windows 上交叉打包）：

```bash
npm ci
npm run dist:mac
```

产物在 `release/` 下，**在哪种 Mac 上打包就出哪种架构**：Apple 芯片出 `arm64` 的 dmg，Intel 出 `x64` 的。也可以直接用仓库里的 GitHub Actions「build-mac」（Apple 芯片 runner，产出 arm64 包），跑完在 Artifacts 里下载。

第一次打开被 Gatekeeper 拦住时：右键点「月相」→「打开」，或执行 `xattr -cr /Applications/月相.app`。原因是安装包没有 Apple 开发者签名。

卸载：Windows 在 设置 → 应用 里卸载；macOS 把「月相」拖进废纸篓。**卸载不会删你的照片和图库。**

## 第一次打开（约 3 分钟）

1. **新建图库**：选一个空文件夹，或选你已有的照片目录。
   - 图库就是一个普通文件夹，里面会多出 `library.db` 和 `thumbnails/` 等索引文件，原图不受影响。
   - 不想让索引文件待在照片目录，可以到「设置 → 存储位置」把它们整体搬到别的盘。
2. **导入照片**：把文件夹直接拖进窗口，或点工具栏「导入图片」。支持 JPEG / PNG / WebP / GIF / BMP / TIFF / AVIF / HEIC 等格式，以及 20 多种 RAW（读相机内嵌的预览图）。
   - 导入中途关掉应用也没关系，下次启动会问你要不要接着导，已入库的不会重复处理。
   - 图库目录里外部新增或删除的文件，会自动同步进来。
3. **开始看**：单击选中（右侧出现信息面板），双击或按空格打开大图。

## 日常怎么用

### 找图

- 顶部搜索框输入关键词，可以再叠加评分、旗标、颜色、横竖构图、文件夹、标签等条件。
- 左侧「智能文件夹」能把当前筛选条件存下来，下次一点就回到同样的结果。
- 语义索引建好后，直接用中文描述找图，或者在某张图上点「找相似」。

### 挑片

- 数字键 `0`–`5` 打星，`P` 留用 / `X` 淘汰 / `U` 清除旗标。
- 连拍自动堆叠，点角标展开；RAW + JPEG 自动配对，默认只显示一张。
- 「查找重复」用画面指纹找出同一张图的不同副本，一键清理。

### 给客户选片

1. 选中要发出去的照片（Ctrl 点选、Shift 连选、Ctrl+A 全选当前已加载的）。
2. 工具栏点「生成选片页」：填标题和客户名，选水印位置与透明度，再选保存位置。
   输出是一张**自包含的 HTML**，图片已经压好、水印烘进像素，断网也能打开。单次最多 999 张。
3. 把 HTML 发给客户。客户双击打开，点「要 / 要修 / 不要」，最后复制一段文字发回给你。
4. 回到应用点「导入选片结果」，把那段文字粘进去 → 预览 → 应用。
5. 左侧会出现「客户已选」，点一下就只看客户要的（含要修的），接着导出成品。

### 交付成品

选中照片 → 工具栏「导出成品」：

- **转成 JPEG**：可选长边（原尺寸 / 2560 / 2048 / 1600 / 1200）、画质，可加水印文字。
- **原件复制**：原样拷贝，RAW、EXIF、色彩配置全部保留。
- 命名可用原名，也可以「前缀-001」连续编号；同名文件不会覆盖，会自动加 `-2`、`-3`。
- 上次用的选项会记住，第二次导出不用重填。

### 学片与复盘（灯箱）

1. 大图里按 `N` 打开右侧档案，切到「研读」。
2. 按 `F`，在画面上拖出一个框，框住你想问的那一块。
3. 写下你的观察或问题，选「AI 反问」或「直接告诉我」。
   - AI 会先反问你，最多两轮，第三轮一定给解释。
   - 没配大模型也能用，纯当笔记本记。
4. 别人的好片子可以在「信息」里勾「这是参考片」，研读模式会自动切过去。
5. 点图上的框，会跳回对应的那条笔记。

### 器材与备份

- 左侧「装备」：录入机身、镜头、配件，按 13 种拍摄场景给出必带 / 可选清单，也能统计每件器材的实际出片量。
- 左侧「维护 → 备份图库」：导出一个 zip；换机器时「从备份恢复」解到新文件夹就能继续用。可以设置按天自动备份并保留最近几份。
- 同一处「导出素材清单」可以把当前筛选结果导成 CSV，交给别人对账或做表格。

### 界面与其它

- **多图库**：左侧栏顶部「月相」旁边的 ⇄ 按钮可以新建 / 切换图库，每个图库各自独立，互不干扰。
- **界面**：6 套皮肤（经典 / 月蚀 / 夜航 / 墨岩 / 柔光 / 雾蓝），也可以跟随系统深浅色；左右两栏宽度能拖，尺寸会记住。
- **缩略图**：工具栏右侧的「缩略图」滑杆可调大小；清晰度默认「自动」，按卡片尺寸和屏幕像素密度挑档，也能手动锁定低 / 中 / 高。
- **拖出去**：按住 Alt 把卡片拖到资源管理器或微信、邮件里，可以直接当文件用。
- **自动分类**：建好语义索引后，可以让它给照片打上「人像 / 风景 / 街拍」这类普通标签，阈值可调，也能一键清除。
- **和 Lightroom / Bridge 配合**：设置里可以打开「XMP 侧车」，把星级、旗标、标签和短备注写到原图旁边的 `.xmp` 里，别的软件能直接读到；只写你手动做过的判断，不写 AI 评分，默认关闭。

## 常用快捷键

macOS 上把 `Ctrl` 换成 `Cmd`；删除也可以直接按 `Backspace`。

| 按键 | 作用 |
| --- | --- |
| 方向键 | 按画面位置移动选择 |
| `J` / `K` | 上一张 / 下一张 |
| 空格 | 打开大图 |
| `0`–`5` | 打星 |
| `P` / `X` / `U` | 留用 / 淘汰 / 清除旗标 |
| `Ctrl + A` | 全选当前已加载的照片 |
| `Ctrl + C` | 复制图片到剪贴板 |
| `Ctrl + Z` | 撤销上一步（最多 20 步） |
| `Delete` | 从图库移出（原图不动） |
| `Esc` | 关闭大图 / 详情 / 取消选择 |

大图里：

| 按键 | 作用 |
| --- | --- |
| `←` `→` | 上一张 / 下一张 |
| 滚轮、`+` / `-` | 缩放 |
| 双击、`0` | 100% 查看 / 适应窗口 |
| `R`、`Shift + R` | 顺时针 / 逆时针旋转（只影响查看，不改文件） |
| `N` | 开关右侧档案 |
| `F` | 开关框选 |
| `Esc` | 先取消框选，再关档案，最后关大图 |

## 数据放在哪

| 内容 | 位置 |
| --- | --- |
| 原图 | 始终在你原来的位置，不改名、不移动、不删除 |
| 索引与缩略图 | 默认在图库目录（`library.db`、`thumbnails/`、`previews/`、`vectors/`），可整体搬到别的盘 |
| 配置与日志 | Windows 在 `%APPDATA%\lunaris`，macOS 在 `~/Library/Application Support/lunaris`，日志只在本地 |
| 备份 | 一个可以拷走的 zip |

删除照片只是把它从图库里移出（标记为已删除），**硬盘上的原图不会被删**；误删可以 `Ctrl / Cmd + Z` 撤销。

## 可选功能（默认关闭）

### 语义搜图（本地模型，只需下载一次）

第一次点左侧「语义索引」会下载模型：

- **Chinese-CLIP**（约 190 MB，中文效果更好，默认）
- **SigLIP 2**（约 393 MB，多语言，可作对比）

下载完就能完全离线用中文搜图与自动分类。几万张的图库建议在「设置 → 语义索引」里打开「闲时自动建立」，让它慢慢跑。

### AI 辅助（用你自己的大模型）

三件事：照片质量评分、单张后期建议、一句话智能筛选。

- 开启方式：设置 → 大模型 → 打开总开关 → 选服务商（OpenAI 兼容接口或 Anthropic）→ 填接口地址和模型名 → 粘 API Key → 点「测试连接」。
- Key 用系统加密保存，界面上只显示 `sk-…abcd` 这样的掩码。
- 总开关不开时，界面上**不会出现任何 AI 按钮**；三个能力还各有独立开关。
- **没有后台自动调用**：只有你点按钮时，才会把压缩后的图片发给你自己配置的服务商。一次评分最多 12 张、智能筛选最多 30 张。
- **量大先打招呼**：批量调用前会粗估这次要花多少 token，量级较大时先弹窗警示，确认后才发请求。
- 评分结果会存进图库，可以按 AI 评分排序、筛选。
- **默认只处理 ★★★ 及以上**：低于门槛、以及没标星的照片，AI 入口会直接藏起来，避免一次把整库都送给模型；想不限星级就选「全部照片」。
- **还能限定文件夹**：同一处可以勾选若干个文件夹，只有这些文件夹里的照片才能用到 AI；不选就是全库。
- **单张也一样**：不在范围内的照片，详情面板里不会出现 AI 评分、AI 后期建议和读片入口；把星级提上来，或去设置里放宽范围，按钮就会出现。已有的评分和笔记不受影响，随时能看。

## 常见问题

**装的时候被 SmartScreen 拦住了？**
正常，安装包没有代码签名。点「更多信息 → 仍要运行」即可。

**换电脑，或者把图库挪到移动硬盘？**
把整个图库目录拷过去，在新机器上点「打开已有图库」。如果照片路径变了，用「维护 → 重新定位」，会按目录、文件名、画面指纹逐层帮你找回来。

**RAW 能调色吗？**
不能。月相只读 RAW 内嵌的预览图，负责看和挑，不代替 Lightroom / Capture One。

**会偷偷上传照片吗？**
不会。除了你主动开启并手动点击的 AI 功能，所有处理都在本机完成。

**索引文件能删吗？**
能，删了下次重新导入或重建即可，原图不受影响。但标签、评分、笔记都存在索引里，删之前先备份。

**同一个图库能在两个窗口打开吗？**
不建议，两个进程会争 SQLite 的锁。想同时看两个图库，用「多图库」功能切换。

## 从旧版本升级

旧版「月巢」的配置、器材库与日志会在首次启动时自动迁移，图库路径和界面偏好不用重配，已下载的语义模型也会复用。确认新版正常后建议卸载旧版——两个版本同时开同一个图库会争锁。

## 给开发者

技术栈：Electron 45 + React 19 + TypeScript，数据用 better-sqlite3，图像处理用 sharp，语义检索用 onnxruntime-node（Chinese-CLIP / SigLIP 2 的 int8 ONNX 模型）。

```bash
npm install
npm run dev        # 开发模式
npm run typecheck  # 类型检查
npm test           # 单元测试
npm run build      # 构建到 out/
npm run dist       # 打包 Windows 安装包到 release/
npm run dist:mac   # 打包 macOS dmg（需在 macOS 上执行）
npm run bench:clip # 语义检索性能基准
```

目录结构：

```
src/main        主进程：数据库、导入、缩略图、备份、查重、语义索引、大模型接入
src/preload     contextBridge 暴露的 window.api
src/renderer    React 界面
src/shared      两端共用的类型与常量
build/          图标与打包资源
design/         界面稿
docs/           方案与实测文档
```

## 已知限制

- 只提供 Windows 与 macOS 的打包配置，Linux 尚未配置。
- macOS 安装包没有 Apple 开发者签名，首次打开需要右键「打开」放行；要分发给别人建议自己配证书并公证。
- macOS 原生模块（better-sqlite3 / sharp / onnxruntime）必须在 macOS 上安装与打包，Windows 上只能打 Windows 包。
- RAW 只读内嵌预览，不支持在应用内调整显影参数。
- HEIC / HEIF 依赖系统的 HEIF 解码器：macOS 自带，Windows 需要装「HEIF 图像扩展」，没装时可能读不出来。
- 语义搜索与自动分类需要先建向量索引，首次耗时与图库规模相关。
- AI 功能依赖服务商：模型必须支持看图；智能筛选只覆盖当前已加载的 30 张。
- AI 评分不会自动失效，原图被替换或换了模型后需要手动重新评分。
