月巢 · 图标方案（深色 / 浅色）

每列同一方案的两种模式；下方 64 / 32 / 16px 为真实尺寸。深色对 classic-dark、eclipse、aurora、graphite，浅色对 classic-light、paper。

深色模式

现行图标

月牙 + 巢弧 + 三颗彩蛋。大尺寸好看，16–32px 时彩蛋糊成噪点。

A3 · 巢月

银月卧在两条巢弧里，去掉彩蛋。最贴近现名，浅色下巢弧会略细。

推荐

B2 · 取景框月

四角取景框 + 银月。摄影识别度最高，深浅两态都能保持形状。推荐。

B3 · 框中有巢

取景框内加一道巢弧当地平线。兼顾两者，小尺寸线条互相争抢。

C2 · 相片叠月

两张叠放的相片卡 + 月牙。浅色下叠卡更清楚，缩到 16px 仍会糊。

适配规则（实施时遵守）
  • 应用内标志去掉底板，只留图形，颜色走 CSS 变量随 [data-theme] 切换：深色用亮蓝紫渐变 + 浅银月，浅色用深蓝紫渐变 + 深墨蓝月。
  • 可执行文件和任务栏图标保持深色底板版本——Windows 不会按系统主题切换程序图标，做两版只会让安装包变复杂。
  • 浅色下 16px 建议单独把线宽加 4px（矢量同源，只换一套描边参数），否则细线在浅底上会发灰。
