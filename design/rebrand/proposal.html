月巢 → 四组新名字与图标

现名「月巢 / MoonNest」偏温软居家，图标里那只巢加三颗彩蛋更像亲子应用。这一版把四组方案的配色全部放开：每组一个主色调，冷感还在，但不至于一片灰黑。

提案四选一
同一个深色基调、同样 512×512 squircle、同样手写矢量。
区别只在主色与意象。
A

银盐Silvergrain

一张照片的起点，是一颗银盐晶体。

  • 摄影的化学本源，器材党与老法师一听就懂
  • 英文生僻、独一无二，好搜好记，不撞名
  • 配色：银白 → 靛蓝 → 紫罗兰 的虹彩金属
冷冽的金属感
B

棱镜Prism

一束白光穿过它，才看得见所有颜色。

  • 光学意象最直白，一眼知道和影像有关
  • 分光 = 从一堆素材里挑出想要的那张
  • 配色：整条光谱搬上三角形，五色一起说话
最跳、色彩最足
C

曜Lumen

光圈开到最大，光才进得来。

  • 六叶光圈是真器材符号，专业感直接拉满
  • 「曜」单字极简，日月星辰皆可承载
  • 配色：香槟金环 + 深青底，像一支老镜
低调的一抹金
D

月相Lunaris

夜里的光最安静，也最适合收拢底片。

  • 延续「月」的 DNA，老用户不会有割裂感
  • 去掉巢与彩球后，从亲子感变成天文台感
  • 配色：紫罗兰星云打底，银月落在中间
最好看、也最稳

怎么选

要最不撞名、最能立住专业人设 → A 银盐 Silvergrain。摄影的根摆在那里，没人会问「这名字什么意思」。

要最好看、最稳妥 → D 月相 Lunaris。星云紫底 + 银月，大图惊艳，16px 下还是全场最清晰。

要色彩最足、一眼看出搞影像 → B 棱镜 Prism，整条光谱直接摆在图标上。

C 曜 Lumen 最硬核最耐看，但细节多，16px 会糊成一团，得 32px 以上才好看。

图标均为手写矢量，已在 16 / 24 / 32 / 48 / 64 / 96 / 512 各档渲染验证。本轮只出方案，尚未改动项目代码。
